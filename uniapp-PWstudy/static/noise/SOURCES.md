# 白噪音素材来源与许可

`static/noise/` 里的五种环境音，两种来源，逐条列清楚。
**换素材前先读 `_tools/build-ambient.py` 文件头的挑选标准**，改完记得同步本文件
（`_tools/check-ambient.js` 会核对两边对不对得上）。

## 程序合成（2 种：雨声 / 沙滩海浪）

| 音色 | 文件 | 来源 | 许可 |
| --- | --- | --- | --- |
| 雨声 | `rain.wav` | 程序合成（无第三方素材） | 零许可义务（synthesized） |
| 沙滩 | `beach.wav` | 程序合成（无第三方素材） | 零许可义务（synthesized） |

雨声与沙滩**之前**是真实录音（雨声 ezwa/pdsounds 公有领域、沙滩 Jarrod stanley/CC0），
但真机反馈「雨声太密集像暴雨、沙滩太连续没有一阵一阵、整体偏吵」—— 这些是**素材性格**，
真实录音改不了：大雨滤波只能变闷、平稳段天然没有涌浪起伏。2026-10-26 起改为**程序合成**，
雨滴密度、涌浪周期、频谱滚降全部可控，离线可播、零许可义务。

二次校准（同日，用户反馈「还是太吵、频率要舒缓、雨要稀疏」）—— 三个维度一起压：
  · **雨滴密度 ~5 滴/秒**（原 12），要"偶尔落几滴"的疏落感；
  · **频谱再压暗**：雨声底噪 1.8k → 1.4kHz，沙滩主体 700 → 600Hz、浪花增益 0.5 → 0.30；
  · **涌浪周期 10s → 15s**（30s 循环里 2 个浪，浪与浪之间隔得更久）；
  · **电平 0.12 → 0.10**（比另外三种噪声低 1.6dB，学习时不抢注意力）。

### 处理方式

合成信号 → 一阶低通控制频谱（雨声底噪 ~1.4kHz、沙滩主体 ~600Hz / 浪花 1k~3.5kHz）
  → RMS 归一（雨声/沙滩 0.10；白/粉/棕噪 0.12 —— 前两者低 1.6dB 是刻意的"不吵"，
    仍在护栏 ±2dB 窗口内，切换音色不会有明显落差）
  → 首尾交叉淡化成无缝循环（把尾部混到头部）。
具体参数写在 `_tools/build-ambient.py` 的 `synth_rain()` / `synth_beach()` 里。

⚠️ 为什么按 RMS 归一而不是峰值：白噪峰值因子只有 3~4dB，按峰值归一会让切到白噪
  突然吵一倍。按 RMS 归一五种音色才一样响（见 noise_util.normalize 的说明）。

## 自己合成（3 种）

| 音色 | 文件 | 来源 |
| --- | --- | --- |
| 白噪 | `white.wav` | `_tools/gen-noise.py` 合成 |
| 粉噪 | `pink.wav` | 同上 |
| 棕噪 | `brown.wav` | 同上 |

噪声类本来就没有"真实采样"可言，自己合成零版权风险、离线可播。

## 共同的处理口径

- 格式一律 **PCM 单声道 16bit**（安卓 MediaPlayer 对别的编码支持不稳）
- 五种音色的 **RMS 全部归一到 0.12**（雨声/沙滩正好与其它三种一致，切换不跳变）
- 首尾交叉淡化成无缝循环，**把尾部混到头部**（方向反了循环点会有样本级跳变）

## 重新生成

```bash
python _tools/build-ambient.py    # 雨声 / 沙滩（程序合成，无需联网下载）
python _tools/gen-noise.py        # 白噪 / 粉噪 / 棕噪
```

两条产线共用 `_tools/noise_util.py` 的柔化 / 归一 / 交叉淡化，不会分叉。
