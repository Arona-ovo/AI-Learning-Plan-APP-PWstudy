## 🌟 这是一个什么 App

一句话：**你负责说"我要在什么时间之前达到什么"，PWstudy 负责回答"那今天该干什么"。**

它不是待办清单，也不是单纯的专注计时，而是一个**闭环的计划系统**：

```
远景目标 ──AI──▶ 里程碑 ──▶ 每日任务
                                  │
                  专注计时执行 ◀────┘
                      │
              今日收工：计划 vs 实际
                      │
        少做了 / 提前做了 / 做了计划外
                      │
              AI 动态重排后面的日程 ──▶ 新计划继续执行 ……
```

- **目标到路径**：告诉它「三个月内专升本英语从 60 到 90」，它会拆出 3~6 个里程碑、每个里程碑下的具体任务（预估专注数、建议截止日、依赖顺序），你逐条勾选后才落地。
- **计划是活的**：今天的执行结果会**间接改变后面的安排**——
  - 少做了 → 先判断状态，状态差只减量不动期限，连续掉队才允许顺延 deadline；
  - 提前做了后面的 → 把那一支整体往前挪；
  - 做了计划外的事 → 后续策略向你实际在做的方向靠拢。
- **完全按计划走完，不打扰**：没有偏差就不惊动 AI，重排只在有 drift 时触发。

## ✨ 五大核心能力

### 1. 🧭 目标向导（AI 远景规划）

- 输入：一句话远景 + 截止日期 + 每天可投入时长 + 当前水平（选填）
- AI 产出（严格 JSON、白名单校验通过才落库，**强制预览**，逐条勾选后生效）：
  - 3~6 个**里程碑**（阶段名 / 起止周 / 目标产出）
  - 每个里程碑下 5~15 个**任务**（标题 / 预估专注数 / 建议截止日 / 标签）
  - 总体策略说明 + 风险提示
- 支持多目标并行，每个目标独立进度
- 支持多轮追问：对计划有疑问，直接问 AI 这一步为什么这么排

### 2. 🍅 专注计时（Focus）

- 可配：专注 / 短休 / 长休时长、长休间隔、自动连开
- 每段专注**绑定一个任务**（也支持自由专注、事后补挂）
- Android 前台服务 + 常驻通知：切后台、锁屏计时照走（按 `endAt` 时间戳驱动，不怕进程被杀）
- **首页硬控**：计时一开始，首页只剩下倒计时（任务列表 / 目标 / Dock 全部收起），
  想看先暂停或结束这一轮 —— 首页在这一刻只该有一件事
- 两档约束，各自独立开关，都只在「正在专注」时生效：
  - **严格模式**（默认关）：切到非学习 App → 提醒 → 30 秒宽限 → 还不回来本次作废（管记账）
  - **强制模式**（默认关）：切到非学习 App → 立刻把 PWstudy 拉回前台；连续 3 次作废（管行为）
  - 放行名单 = PWstudy 本身 + 「学习 App」里登记为「学习」的 App + 系统中性包（桌面 / 设置 / 电话…）
- **专注白噪音**（默认关）：白噪 / 粉噪 / 棕噪 / 雨声，本地合成循环播放，休息自动停
- 中断自动标记，不计入有效专注
- 假期与周末自动减量（假期 ×0.5、周末 ×0.8，确定性规则，不靠 AI 自觉）

### 3. 📱 AppDock —— 学习 App 用时统计

- 勾选你的「学习类 App」（背单词 / 刷题 / 看课 / 阅读 / 笔记），首页 Dock 一键拉起
- 两条腿计时：从本 App 发起的跳转（无需权限，可归因到任务）+ `UsageStats` 全量校准（需手动授权一次）
- 展示值取两者较大，**数据只存本地，不上传**

### 4. 🌙 今日收工 —— 计划 vs 实际

每天收工时填一张对照表（或直接在首页跟 AI 对话一句"今天背了 200 词但没做阅读"）：

- **少做了** / **提前做了后面的** / **做了计划外**，三者任一命中即触发重排
- 对话里 AI 提炼的事实自动进当日记录；"做完了 X"会真实记入专注数（只增不减）
- 填表和对话两个入口写**同一份数据**，重排只读这一份真相

### 5. 🔁 动态重排（Replan）

- AI 输入：目标 + 里程碑 + 剩余任务 + 近 14 天真实投入 + 偏差明细
- AI 输出 **diff 而非全量覆盖**：`move`（改期）/ `resize`（增减专注数）/ 拆合 / `drop`（砍低价值任务并说明原因）
- 已完成任务**永不改动**；所有调整先预览，你逐条接受才落库
- 也可手动触发，或按周复盘

## 🧪 自动化校验

```bash
# 改完 .vue 先跑（秒级语法检查，比等 HBuilderX 编译快得多）
node _tools/check-vue.js

# 数据层与引用完整性
node _tools/check-pwstudy.js && node _tools/check-refs.js

# 全量回归（63 个，约 3 分钟）
node _tools/_scratch/run-all.js
```

> 所有校验脚本都是只读 / 幂等的：运行时会接管 `process.exit`、临时目录用完即删，不会改动工程文件。
> `_tools/_scratch/neg-*.js` 是配套反向测试 —— 故意把源码改坏，确认护栏真的会红（防假绿）。
